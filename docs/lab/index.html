Eight directions, one subject

Eight complete pages, each committing hard to a different visual language. Every one is a single self-contained file — no framework, no build step, no network — and every animation has a reduced-motion path. The 3D is a 200-line wireframe renderer written for this lab rather than a library.

How to read these

These are deliberately not eight variations of the real site. Each one commits fully to a position so you can see what that position costs and what it buys. 04 and 02 are the closest to something you could actually ship for Quantum Ready; 05 would be memorable to engineers and alienating to a compliance officer; 01 and 07 are the ones to raid for individual moves rather than adopt whole.

Every page keeps the non-negotiables: visible focus rings, 44px targets, honest heading order, and a reduced-motion path that renders the final state instead of leaving content invisible. Loud is a style choice; inaccessible is a bug.
