Perlin flow field · 1,400 particles

Order emerges
from noise.

Every particle follows the same rule and none of them were told where to go. Move your cursor and the field bends around it — the structure is entirely a consequence of local decisions.

1,400

Agents

Each reads the field at its own position and steps. No agent knows about any other.

0

Value noise, a vector field and a canvas. No library, no build step, no network.

Budget
