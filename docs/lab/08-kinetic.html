A larger key buys you nothing. RSA-15360 falls to the same algorithm as RSA-2048, only marginally later.

Grover halves your symmetric strength. That is survivable. Shor takes public-key security to zero. That is not.

The deadline is not when the machine arrives. It is that date minus how long your data must stay secret.
